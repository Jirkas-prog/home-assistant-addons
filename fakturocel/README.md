# Fakturocel

Fakturocel is a self-hosted invoicing add-on for Home Assistant OS. It provides invoices and quotes, PDF and readable Excel export, archived-document reprinting, reports, review tasks, calculators, complete ZIP/Excel backups, optional automatic Google Drive backups, local and cloud restoration, and a visual invoice-template editor.

The workspace uses a main sidebar, contextual horizontal tabs, and searchable settings. Encryption switches are directly available under **Settings → Backups and encryption**.

The add-on starts empty and contains no personal business data. English is the default interface language; Czech can be selected and is stored under **Settings → General → Language**.

Install it from `https://github.com/Jirkas-prog/home-assistant-addons`. See [DOCS.md](DOCS.md) for configuration, backup, recovery, deletion, and network-endpoint details.
