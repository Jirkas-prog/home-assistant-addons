Welcome to MyBrowser

All your websites in one place.

This page is a real hosted website running inside the add-on. It also shows how to add a project, upload files, and open it directly in the main workspace.

Static website through the gateway
http://HOME_ASSISTANT_IP:3000/mybrowser-guide/

Your first website in three steps

Use ＋ Add → Hosted website in the MyBrowser header.

1

Name the website

The path is prepared automatically as /share/Websites/001_WebsiteName. The shared gateway is the default access mode.

2

Drop your files

Drop individual files or an entire folder into the left panel. Uploading starts immediately and safely continues in the background after website creation.

3

Open the card

Clicking the card opens the website in the main MyBrowser workspace. “Open separately” remains available as an additional option.

Cover images and automatic previews

A custom image takes priority

Drop a JPG, PNG, WebP, GIF, or AVIF into the right-hand panel. Without a custom image, MyBrowser renders the home page once at 1900 × 1069 px and stores it as a static PNG preview.

No unnecessary refreshes

The preview is not rendered live. It is captured again only after the website files change.

Gateway and server management

One public gateway

The default port is 3000. Each website receives its own path, such as /my-website/.

Three access modes

Alongside the default gateway, you can enter a public URL from your own reverse proxy or keep a dedicated custom port for the project.

Technical management and files

Server Management provides start, restart, logs, and settings. The Files tab supports folders, bulk selection, copying, moving, renaming, downloading, and deletion.

Tip: The three-dot menu on each card can copy the address, open settings, or hide the card from Home without deleting it. Header search can open web results directly in MyBrowser, and “Make available offline” adds the current page to the library.

The guide is a regular managed website. You can inspect or edit its files, or remove it. Once removed, it is not created again automatically.
